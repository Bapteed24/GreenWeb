# GreenWeb

Site vitrine d'une agence web fictive basée à Niort.

GreenWeb accompagne les entreprises et associations de la région dans la création et la maintenance de leur présence en ligne.

## Le projet

L'objectif est de créer un site moderne, simple et agréable à utiliser pour présenter les services de l'agence, ses réalisations et permettre aux visiteurs de prendre contact.

Le projet me sert également à approfondir React et TypeScript en construisant un projet complet de A à Z.

## Stack

- React
- TypeScript
- Vite
- CSS
- Node.js

## Fonctionnalités

- Présentation de l'agence
- Services proposés
- Portfolio / réalisations
- Formulaire de contact
- Navigation responsive
- Authentification et espace administrateur

## Design

Une identité visuelle sobre et naturelle :

- tons verts
- fond crème
- interface épurée
- animations discrètes
- responsive desktop / mobile
